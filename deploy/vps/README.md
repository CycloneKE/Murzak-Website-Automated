# VPS-side files for app subdomain routing

Source of truth for the nginx config and helper scripts that make
`*.apps.murzaktech.tech` reachable. These are **deployed to the VPS**, not used
by the Node app — kept here so they are version-controlled rather than living
only on `srv1657915`.

See [`docs/app-subdomain-routing.md`](../../docs/app-subdomain-routing.md) for
the design and the reasoning behind it.

## Install targets

| Repo file | Destination on the VPS | Mode |
|-----------|------------------------|------|
| `nginx/00-murzak-apps-map.conf` | `/etc/nginx/conf.d/00-murzak-apps-map.conf` | 0644 root:root |
| `nginx/apps.murzaktech.tech` | `/etc/nginx/sites-available/apps.murzaktech.tech` | 0644 root:root |
| `nginx/murzak-app-proxy.conf` | `/etc/nginx/snippets/murzak-app-proxy.conf` | 0644 root:root |
| `bin/murzak-app-vhost` | `/usr/local/bin/murzak-app-vhost` | 0755 root:root |
| `bin/murzak-app-vhost-remove` | `/usr/local/bin/murzak-app-vhost-remove` | 0755 root:root |
| `bin/murzak-app-sync` | `/usr/local/bin/murzak-app-sync` | 0755 root:root |
| `systemd/murzak-app-sync.service` | `/etc/systemd/system/murzak-app-sync.service` | 0644 root:root |
| `systemd/murzak-app-sync.timer` | `/etc/systemd/system/murzak-app-sync.timer` | 0644 root:root |

`sites-available/apps.murzaktech.tech` must be symlinked into
`sites-enabled/`. The per-host `app-<fqdn>` vhosts are generated by
`murzak-app-vhost` and are deliberately **not** tracked here.

After installing the units:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now murzak-app-sync.timer
```

## Prerequisites on the box

- `/var/www/certbot/.well-known/acme-challenge/` exists (ACME webroot).
- `server_names_hash_bucket_size 128;` is set in `nginx.conf` — the default 64
  is too small for the ~64-character hostnames the provisioner generates.
- A wildcard DNS record `*.apps.murzaktech.tech A -> 187.124.217.78`.
- A self-signed fallback certificate for the `:443` catch-all:

  ```bash
  sudo mkdir -p /etc/ssl/murzak
  sudo openssl req -x509 -nodes -newkey rsa:2048 -days 3650 \
    -keyout /etc/ssl/murzak/apps-fallback.key \
    -out /etc/ssl/murzak/apps-fallback.crt \
    -subj "/CN=unpublished.apps.murzaktech.tech" \
    -addext "subjectAltName=DNS:*.apps.murzaktech.tech,DNS:unpublished.apps.murzaktech.tech"
  sudo chmod 600 /etc/ssl/murzak/apps-fallback.key
  ```

## Deploying a change

Always validate before reloading; this box serves unrelated live customer
sites.

```bash
sudo nginx -t && sudo systemctl reload nginx
```
